# Wi-Fi Connectivity

## Overview
Use this article if your laptop cannot find the corporate Wi-Fi, keeps disconnecting or shows "No internet".

## Steps
1. Make sure Airplane mode is off and the Wi-Fi switch or key on the laptop is on.
2. Turn Wi-Fi off and on again, then choose the CORP-WIFI network.
3. Select Forget this network, reconnect and sign in with your company credentials.
4. Restart the laptop. Many Wi-Fi drivers recover after a restart.
5. Move closer to an access point. Concrete walls and lifts weaken the signal.
6. Use the guest network only for internet access; it cannot reach internal applications.

## Escalation
If several colleagues near you have the same problem, report it to Network Support as a team-wide incident, because an access point may be down.
