# Application Restart and Cache Clearing

## Overview
Many application problems such as freezing, blank windows or old data are fixed by restarting the application and clearing its cache. These actions are safe because they do not delete your documents.

## Restart an application
1. Save your work and close the application from the taskbar.
2. If it does not close, end the task in Task Manager.
3. Open the application again.

## Clear the cache
1. Microsoft Teams: close Teams and delete the contents of the Teams cache folder, then reopen it.
2. Browser: clear cached images and files from the browser settings.
3. Outlook: see the Outlook Synchronization article.

## Automated help
The helpdesk assistant can restart an application or clear its cache automatically and then confirm that it is running again.
