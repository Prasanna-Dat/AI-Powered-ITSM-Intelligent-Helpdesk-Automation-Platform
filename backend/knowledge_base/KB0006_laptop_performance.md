# Laptop Performance

## Overview
Use this article if your laptop is slow, freezes, or the fan runs loudly all the time.

## Quick fixes
1. Save your work and restart the laptop. A restart once a week keeps updates and memory healthy.
2. Open Task Manager (Ctrl+Shift+Esc), sort by CPU and Memory, and close applications that use a lot of resources.
3. Disable unneeded startup programs from the Startup tab in Task Manager.
4. Make sure at least 15 percent of the disk is free. Delete large downloads and empty the Recycle Bin.
5. Install pending Windows and company updates from the Software Center.
6. Keep the laptop on a hard surface so the fan can cool it.

## Escalation
If the laptop is still slow after these steps, raise an incident for Desktop Support. Include the laptop asset tag and when the slowness started.
