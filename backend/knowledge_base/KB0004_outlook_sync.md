# Outlook Synchronization Issues

## Overview
Use this article when Outlook shows "Disconnected", "Updating inbox" for a long time, or new emails and calendar items do not appear.

## How to troubleshoot Outlook synchronization
1. Check that you have internet access and that Outlook is not in Work Offline mode (Send/Receive tab, Work Offline must not be highlighted).
2. Press F9 to force a Send/Receive and check the status bar at the bottom of Outlook.
3. Check that your mailbox is not full. Empty Deleted Items and Archive large attachments.
4. Close Outlook fully, then reopen it. If it is still stuck, restart the computer.
5. Clear the Outlook cache: close Outlook, then rename the folder %localappdata%\Microsoft\Outlook and reopen Outlook so it rebuilds the cache.
6. Create a new Outlook profile from Control Panel, Mail, Show Profiles, Add.

## Automated help
The helpdesk assistant can restart Outlook and clear its cache for you after confirming the issue is safe to automate.

## Escalation
If Outlook still does not sync after a new profile, raise an incident for Messaging Support with a screenshot of the error.
