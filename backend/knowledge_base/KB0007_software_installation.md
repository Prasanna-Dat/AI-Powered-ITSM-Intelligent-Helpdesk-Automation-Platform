# Software Installation

## Overview
Only approved software from the Software Catalogue can be installed on company laptops. Employees cannot install software from the internet.

## How to get approved software
1. Open the Self-Service portal and describe the software you need, for example "I need Visual Studio Code installed".
2. The assistant checks the Software Catalogue and creates a ServiceNow service request.
3. Standard catalogue items are approved automatically and are installed within a few minutes while your laptop is online.
4. You will see the status change from Requested to Provisioning to Completed.

## Software that is not in the catalogue
Software that is not in the catalogue needs manager and security approval. Raise a service request with a business justification.

## Troubleshooting a failed install
Restart the laptop and check that you have at least 5 GB of free disk space. If the install still fails, raise an incident for Desktop Support.
